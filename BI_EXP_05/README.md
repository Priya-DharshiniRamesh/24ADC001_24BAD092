# Business Intelligence Lab – Experiment 5
## Develop Interactive Dashboards for Dynamic Data Exploration using Tableau & Power BI

This repository contains the implementation of **Business Intelligence Experiment 5**, where Tableau and Power BI were used to design and develop interactive dashboards on retail sales data, enabling dynamic exploration through filters, slicers, drill-downs, and parameters.

---

## 🎯 Objective

To design and develop interactive dashboards in **Tableau** and **Power BI** for dynamic data exploration, enabling users to analyze, filter, and drill down into data for deeper insights.

---

## 🛠️ Tools Used

- Tableau Desktop
- Microsoft Power BI Desktop
- Power Query
- Calculated Fields
- DAX Measures

## 📊 Dataset

### Retail Sales Dataset

### Fields Used

| Field | Description |
|-------|-------------|
| Order Date | Date of the order |
| Region | Sales region |
| Product Category | Category of product sold |
| Sales | Sales revenue |
| Profit | Net profit from the order |
| Quantity | Units sold |

---

## 🔄 Data Preparation & Transformation

- Ensured proper date formats for time-based analysis
- Handled missing or incorrect values
- Created calculated fields such as:
  - Profit Margin %
  - Sales Growth %
  - Year-to-Date Sales
- Created hierarchies (Year → Quarter → Month → Day)
- Aggregated data by region, product category, and customer segment

---

## 🎛️ Interactive Elements Designed

- **Filters & Slicers** – filter by product category, date range, or region
- **Parameters** – switch between KPIs (e.g., Sales vs. Profit)
- **Drill-down** – explore data from summary to detail (Year → Month → Day)
- **Drill-through** (Power BI) – navigate to detailed report pages
- **Tooltips** – contextual details on hover
- **Filter & Highlight Actions** (Tableau) – cross-filtering between visuals
- **Bookmarks & Buttons** (Power BI) – guided navigation across the report

## 📚 Key Learning Outcomes

- Understood dynamic data exploration and its importance in BI tools.
- Learned how slicers and filters enhance dashboard interactivity.
- Explored drill-down and drill-through features in Tableau and Power BI.
- Learned the role of parameters in building flexible, scenario-based dashboards.
- Discovered advanced interactivity features: tooltips, cross-filtering, bookmarks, and actions.
- Built hierarchies for time-based drill-down analysis.
- Understood the importance of publishing and sharing interactive dashboards.

---

## 📈 Key Findings

- Interactivity significantly improved the ease and speed of data exploration.
- Filters and slicers were the most useful feature, enabling quick focus on specific regions, categories, and time periods.
- Setting up date hierarchies and visual interactions required careful configuration for drill-down to work correctly.
- Tooltips improved dashboard storytelling by providing contextual detail without clutter.
- The resulting dashboards enabled fast, flexible comparison of sales and profit trends across region, category, and time.
